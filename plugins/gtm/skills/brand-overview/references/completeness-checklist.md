# Brand Completeness Checklist

This is the canonical checklist used to score brand system completeness. Each item is scored as **present** (concrete values extracted), **partial** (mentioned but incomplete), or **missing** (not found).

## Scoring

- Present = 1 point
- Partial = 0.5 points
- Missing = 0 points
- Overall score = (total points / total items) × 100

## 1. Foundations (7 items)

| # | Item | What counts as "present" | What counts as "partial" |
|---|------|-------------------------|------------------------|
| 1.1 | Purpose statement | A clear sentence explaining why the brand exists beyond profit | Vague or generic purpose |
| 1.2 | Mission statement | Specific, actionable mission | Exists but indistinguishable from vision |
| 1.3 | Vision statement | Aspirational future state | Vague or same as mission |
| 1.4 | Brand values | 3-6 named values with descriptions | Values listed without explanation |
| 1.5 | Brand personality | Named traits with behavioural descriptions | Adjective list without guidance |
| 1.6 | Brand story / narrative | Origin story or strategic narrative | Brief mention without structure |
| 1.7 | Tone of voice | Voice principles with do/don't examples | General tone descriptor without examples |

## 2. Logo (6 items)

| # | Item | What counts as "present" | What counts as "partial" |
|---|------|-------------------------|------------------------|
| 2.1 | Primary logo | Logo file or detailed description + usage context | Mentioned but no file or spec |
| 2.2 | Logo variations | Light, dark, mono versions documented | Only one version shown |
| 2.3 | Clearspace rules | Specific measurement (e.g. "height of the 'e'") | "Leave adequate space" without specifics |
| 2.4 | Minimum size | Pixel/mm minimum stated | "Don't make it too small" |
| 2.5 | Favicon / app icon | Specific favicon design documented | Logo used as favicon without adaptation |
| 2.6 | Logo misuse | Specific don'ts with visual examples | Generic "don't alter the logo" |

## 3. Colour (6 items)

| # | Item | What counts as "present" | What counts as "partial" |
|---|------|-------------------------|------------------------|
| 3.1 | Primary palette | Named colours with hex values and roles | Hex values without names or roles |
| 3.2 | Secondary / accent palette | Additional colours with hex and usage | Colours shown but not named/roled |
| 3.3 | Semantic colours | Success, error, warning, info defined | Only one or two semantic colours |
| 3.4 | Gradient definitions | Specific gradient specs (stops, angles) | "We use gradients" without specs |
| 3.5 | Dark mode palette | Full dark mode colour mapping | Partial or "invert the colours" |
| 3.6 | Colour usage rules | When/where to use each colour | Colours listed without usage guidance |

| # | Item | What counts as "present" | What counts as "partial" |

### Scoring tiers

| Score | Rating | Label |
|-------|--------|-------|
| 90-100% | Exceptional | Comprehensive brand system |
| 75-89% | Strong | Well-developed, minor gaps |
| 60-74% | Solid | Good foundation, notable gaps |
| 40-59% | Developing | Key elements present, significant gaps |
| 20-39% | Early | Basics only |
| 0-19% | Nascent | Just getting started |
