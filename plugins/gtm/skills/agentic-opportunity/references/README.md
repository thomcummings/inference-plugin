# Agentic opportunity — durable lens

Deep detail the `agentic-opportunity` skill reads on demand, so the SKILL.md stays a
lean selector.

**What lives here:** only the *durable* judgement — frames that don't rot. The
adoption curve, the agent-suitability frontier, the build-shape layers, the economics
agents change, and the honest tradeoffs.

**What deliberately does NOT live here:** anything about what a specific tool or model
can do *right now*. That goes stale within weeks. The skill gets current capability
from a live web search at runtime, dated and cited. Do not add a "current tools" file
here — it would be wrong by the next quarter and is the exact failure this design
avoids.

Files:

- `adoption-curve.md` — Chat → Automation → Augmentation → Agentic → Autonomous.
- `agent-suitability-and-build-shape.md` — the moving frontier of agent-suitable work,
  plus Identity / Capability / Governance for shaping a role once it's worth building.
- `economics-and-honest-tradeoffs.md` — the five economics agents change, and the real
  costs that keep the bullishness honest.

Expandable: if a durable frame is missing, reason from first principles, say it's
missing, and add a file. Keep capability facts out — search for those.
