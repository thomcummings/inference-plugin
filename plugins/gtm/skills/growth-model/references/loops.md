# Growth loops vs funnels

**What it is.** A loop is a closed cycle where the output of one cycle becomes the
input to the next, so growth compounds without proportional new spend. A funnel is a
one-way path (awareness → conversion) that leaks and must be constantly refilled.
Loops are the frame, not a separate motion — every motion below either has a loop or
is really a funnel wearing a loop's clothes.

**When it fits.** Almost always worth *testing for* — every business should know
whether it has a loop or just a funnel. A real loop exists when you can name the
reinvestment: new users/content/revenue/data from this cycle measurably drive the
next (e.g. user-generated content ranks and pulls more users; each new user invites
others; usage produces data that improves the product that wins more users).

**When it doesn't.** Don't force a loop where none exists. Many honest B2B businesses
grow through a *funnel fed by a sales or content engine* — that's fine; call it what
it is rather than drawing a loop diagram that doesn't reflect reality. Paid
acquisition with no compounding is a funnel, not a loop, however much you spend.

**Engine shape.**
- Engine: the loop itself (content loop, viral/invite loop, paid-payback loop,
  sales-referral loop, data/network-effect loop).
- Fuel: what the loop consumes each turn (users, content, capital, data, proof).
- Lubricants: activation, conversion, retention — they raise the loop's gain.
- Boosts: one-off spikes (PR, launch) that do not feed the next turn.
- Reinvestment: the explicit mechanism by which this turn's output becomes next
  turn's input. If you can't name it, you have a funnel.

**Fit tests that bite.** Reinvestment mechanism (is there one?); loop gain (does each
turn produce *more* than one next-turn input, or is it decaying?); time-to-loop (how
long is one cycle — a 12-month sales loop compounds slowly).

**Decay signals.** Loop gain falling below replacement (each cycle yields fewer
inputs than the last); rising reliance on paid/boosts to keep volume; saturation of
the source (the addressable pool the loop draws from is exhausting).

**Lineage.** Reforge / Brian Balfour (loops, the racecar); Andrew Chen (channel decay,
the law of shitty click-throughs); contrast with classic AARRR funnel thinking.
