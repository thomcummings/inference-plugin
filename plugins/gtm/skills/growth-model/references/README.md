# Model & motion library

Deep profiles the `growth-model` skill reads on demand, so the SKILL.md stays a lean
selector. Read the relevant profile when mapping the model and choosing the motion.

Each profile follows the same shape:
**What it is · When it fits · When it doesn't · Engine shape · Fit tests that bite ·
Decay signals · Lineage.**

The library is expandable. If the right model isn't here, reason from first
principles, say the profile is missing, and add a new file so the next run inherits
it. Keep new files to the same shape.

Current profiles:

- `loops.md` — growth loops vs funnels (the racecar logic; the cross-cutting frame)
- `plg.md` — product-led growth and product-led sales
- `sales-led.md` — sales-led and sales-assisted inbound
- `founder-led.md` — founder-led sales / founder-led growth
- `community-led.md` — community and ecosystem pull
- `partner-led.md` — partner / channel / white-label motions

One entry deliberately breaks the shape above, because it isn't a motion:

- `retention.md` — retention, churn and expansion. The diagnostic for a leaking base:
  voluntary vs involuntary, where voluntary churn actually comes from, what bites when you
  measure it, and when retention work is the wrong answer.
