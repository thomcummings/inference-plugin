# Week one: grounding the engagement

Settle these before the workshop. Where the client has no view, use the default and record it as a draft decision.

## Questions to answer with the client in week one
| Question | Default if no view |
| --- | --- |
| What does the headline metric actually count? | Split it by origin before deciding anything |
| Who owns the list? | ABM owner, with sales sign-off |
| How big is Tier 1? | What the team can work one-to-one; often 8–15 for a small team |
| Is there one segment or several? | Tag a segment per account, and filter everywhere |
| What counts as Aware? | High-intent visits, ad engagement, event attendance |
| Which meeting becomes the ABM weekly? | The existing sales or account review |
| Which system holds next steps? | The command center first, mirrored to CRM tasks |
| Can we de-anonymize web traffic? | A GDPR-compliant company-level tool, with coverage caveats stated |
| What is a PQL here? | Draft a usage threshold and get sales sign-off |

## Systems you'll need (any vendor)
- A CRM with a custom company property, segments, tasks and API read access
- Product analytics with domain-level grouping
- Company-level website visitor identification
- Ad platforms with list-based or matched audiences
- A team chat with channels and, ideally, shared channels with key accounts
- A hosted page or app with a small document store for the command center (or CRM custom views)
- A scheduler or agent runtime for routines, plus a place to register them with owners, trial status and review dates (the client's agent hub, if they have one)

Vendor names in any example are illustrations, not requirements. Record what each system covers and what the access scopes hide.
