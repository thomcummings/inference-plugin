# Assembly & the coherence pass (Job 1)

The spine of the skill. A selling system is not a folder of assets — it's a set of
claims that all trace back to the same positioning, each backed by proof, each
sayable by a real seller. This file covers how to assemble it and, more importantly,
how to run the coherence pass that turns a pile into a system.

## Contents
- The assembly order
- The proof map
- The objection map
- Competitive battlecards
- The coherence pass — five failure modes
- Grading evidence

## The assembly order
Assemble in this order, because each layer feeds the next:

1. **Buyer & fit** — pull the ICP snapshot and the trigger signals. This scopes
   everything else: the system is *for* winning this buyer, not any buyer. Hand the
   detail to Job 2 (discovery/qualification).
2. **Narrative spine** — take the positioning's sales-pitch translation (setup →
   insight → stakes → resolution). Do not rewrite it; if it doesn't exist, route to
   `positioning` first and proceed on a labelled draft.
3. **Proof map** — every claim in the narrative gets a proof and a source.
4. **Objection map** — the recurring objections, each with a reframe and the proof
   that backs it, sourced from win-loss reality.
5. **Competitive battlecards** — per rival: their pitch, our wedge, the trap to avoid.
6. **Coherence pass** — walk the whole thing and flag the failure modes below.

## The proof map
The load-bearing artefact. One row per claim:

```
Claim (in buyer's language) | Proof | Proof type | Source | Evidence grade
```

- **Proof type**: customer result, third-party validation, demo-able capability,
  reference customer, data point. Rank these — a customer result outranks a feature
  demo outranks a bare assertion.
- **Evidence grade**: validated (real, sourced) vs hypothesis (plausible, unsourced).
  A claim with no proof is an **orphan** — flag it, don't ship it.

## The objection map
```
Objection (as the buyer says it) | What's really behind it | Reframe | Proof | Source
```
The "what's really behind it" column is where the judgement lives — most objections
are proxies (price often means unclear ROI; "no time" often means unclear priority).
Source objections from win-loss, not imagination. If you're inventing them, say so and
route to `win-loss-analysis`.

## Competitive battlecards
One per meaningful rival. Built from win-loss and competitive-scan, never the rival's
website:
```
Rival | Their pitch | Where they genuinely win | Our wedge | The trap (how we lose to them) | One-line reframe
```
"Where they genuinely win" is non-negotiable — a battlecard that pretends the
competitor has no strengths gets a seller ambushed. Honesty here is what makes the
wedge credible.

## The coherence pass — five failure modes
This is the move a blank model won't make. Walk the assembled kit and flag:

1. **Orphan claims** — a claim with no proof. Find proof or cut it.
2. **Contradictions** — an asset that fights the positioning or another asset (a
   battlecard claiming enterprise-grade security while the positioning targets
   scrappy startups; two talk tracks with different primary value props). Name both
   sides; resolve to the positioning.
3. **Website battlecards** — competitive/objection content not grounded in win-loss.
   Mark unvalidated; route to `win-loss-analysis`.
4. **Unrepeatable differentiation** — if a seller can't say it in one sentence they'd
   actually use, it isn't done. Rewrite until it's sayable.
5. **Positioning drift** — live language that has wandered from the current
   positioning. Flag for the consistency sweep.

Output the flags as a **coherence-gap list** with a recommended fix and the cheapest
next proof for each. Don't smooth them over — the flags are the value.

## Grading evidence
Carry the Inference evidence discipline throughout: validated vs hypothesis, labelled;
confidence lives in the evidence, not adjectives; thin evidence caps confidence but
doesn't stop the work. The cheapest way to thicken almost everything here is the same:
read five won-deal and five lost-deal calls.

Lineage: Dunford (sales pitch, positioning root), win-loss practice, Inference
doctrine (evidence grading, lead with the call).
